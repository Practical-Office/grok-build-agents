# AGENTS.md — Grok Build Agents Course

## Rules for anyone working on this repo

- Keep language plain and step-by-step. Assume little technical knowledge.
- Prefer short paragraphs and numbered steps.
- Every module must reinforce Plan Mode and safety.
- Do not add advanced features (MCP, headless, multi-agent orchestration) until the core modules are solid.
- Update `docs/reference/GROK-BUILD-AGENTS-PROCESS.md` before changing module wording.
- Evidence of success must be binary and checkable (file exists, plan was approved, tool works).

## Tone

Clear. Direct. No fluff. No marketing language. Protect the learner’s time.
