Manager agent

Optional coordination agent for after you have at least two narrow worker agents in separate folders. A Manager routes jobs — it never does the work itself.

When to use this

  • You already completed the core course (Modules 1–5).
  • You have two or more narrow agents, each at Trust Stage 1 or higher, each in its own folder.
  • You want one place to decide which agent folder to open for an incoming job.

The core course does not include a Manager build lab. Worker agents still use Plan Mode in their own folders.

Full rules: Living process — Manager agents

Pinned build paste (Grok Build CLI)

Create a dedicated Manager folder, cd into it, start grok, and paste:

You are my Manager agent. You never do any task yourself. When a job comes in, assign a dedicated sub-agent for that one job. One agent, one lane. Coordinate and report back to me. Use Plan Mode. Do not make any changes until I approve the plan.
