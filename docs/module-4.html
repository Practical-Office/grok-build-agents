Module 4 of 5 · 60–90 min

First Real Agents (Labs)

Build two small, useful agents in separate folders. Always use Plan Mode inside the Grok Build CLI.

Before you start — create separate folders

In the terminal (not inside Grok), run:

mkdir -p ~/agents/daily-tracker
mkdir -p ~/agents/follow-up-helper

Each lab uses its own folder. Do not mix agents.

Lab A — Daily Activity Tracker

Outcome: A simple checklist for calls, emails, meetings, and notes.

Where:

cd ~/agents/daily-tracker
grok

Paste into Grok Build CLI:

Build a clean daily activity tracker as a markdown file called daily-activity.md.
Sections: Calls, Emails, Meetings, Notes, Top priority for tomorrow.
Keep it simple and easy to fill out by hand each day.
Use Plan Mode. Do not make any changes until I approve the plan.
  1. Approve only if the plan creates that one file with those sections.
  2. Open the file and confirm it is usable.
  3. Then paste:
Improve daily-activity.md with one small improvement only (for example clearer section headers).
Use Plan Mode. Do not make any changes until I approve the plan.

After it works, save the skill:

/skillify

When asked for a name, use: daily-activity-tracker

Lab B — Follow-up Helper

Outcome: Given short notes, produce a clear professional follow-up message.

Where:

cd ~/agents/follow-up-helper
grok

Paste into Grok Build CLI:

Create a simple follow-up helper in this folder.
I will give you 2–4 bullet points about a conversation.
You return a short, clear follow-up message I can send.
Tone: professional, direct, no fluff.
Write a short IDENTITY.md with that job description and hard boundary: draft messages only, never send.
Use Plan Mode. Do not make any changes until I approve the plan.

After the plan is approved and files exist, test with a non-sensitive example:

Using the follow-up helper rules, draft a message from these notes:
- Met with Alex about project timeline
- They asked for a revised delivery date next Friday
- I agreed to send an update by Wednesday

Use Plan Mode. Do not make any changes until I approve the plan.

Run a second real (non-sensitive) example the same way. Do not use client or personal data you would not share with a colleague.

Best practices while building

  • One change at a time.
  • Always re-state “Use Plan Mode” on new requests.
  • If the plan is long or unclear, paste: Simplify the plan. Keep only the minimum steps. Use Plan Mode.
  • Keep each agent in its own folder.
