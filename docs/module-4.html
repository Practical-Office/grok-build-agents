Module 4 — First Real Agents (Labs)

Build two small, useful agents using everything you have learned. Keep them narrow and always use Plan Mode.

Before you start

Create a fresh folder for each lab. Do not mix agents in the same folder.

Lab A — Daily Activity Tracker

Outcome: A simple checklist you can fill out each day for calls, emails, meetings, and notes.

Prompt starter:

Build a clean daily activity tracker as a markdown file.
Sections: Calls, Emails, Meetings, Notes, Top priority for tomorrow.
Keep it simple and easy to fill out.
Use Plan Mode. Do not make changes until I approve.

After it works:

  1. Review the file.
  2. Make one improvement (ask Grok with Plan Mode).
  3. Run /skillify and name the skill something clear like daily-activity-tracker.

Lab B — Follow-up Helper

Outcome: Given a short note about a conversation, the agent produces a clear follow-up message in a professional tone.

Prompt starter:

Create a simple follow-up helper.
I will give you 2–4 bullet points about a conversation.
You return a short, clear follow-up message I can send.
Tone: professional, direct, no fluff.
Use Plan Mode. Do not make changes until I approve.

Test it with two real (non-sensitive) examples from your work. Adjust the identity/playbook until the output feels right.

Best practices while building

  • One change at a time.
  • Always re-state “Use Plan Mode” on new requests.
  • If the plan is long or unclear, ask Grok to simplify it.
  • Save working versions. Do not keep editing the only copy until it breaks.
Done when

You have finished both labs, each agent is in its own folder, and at least one useful skill has been saved with /skillify.
