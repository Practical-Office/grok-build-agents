Module 2 — Aim + Identity

Before an agent can work well, it needs a clear outcome and a clear identity.

1. Aim for a specific outcome

Do not start by listing steps. Start by stating the result you want.

Weak: “Help with my emails.”

Strong: “Every morning the inbox has drafts ready in my voice, important items are flagged, and nothing important is missed.”

Also write a Definition of Done — one sentence that tells the agent when the job is finished.

Template you can copy
I need to [outcome].
Why this matters: [short reason].
Definition of Done: [one clear, measurable sentence].
Use Plan Mode. Ask me any clarifying questions first.

2. Give the agent an identity

Out of the box, an AI knows a little about everything and nothing deeply. Identity focuses it.

Create three plain-English files (let Grok write them for you):

FileWhat it is
SOULPersonality, tone, values, and how it behaves
IDENTITYName, role, job description, and hard boundaries (what it must never touch)
USERWho it works for — your role, priorities, and preferences

Prompt to generate all three:

I want to build an AI agent that [paste your Aim / outcome].
Create its three identity files: a SOUL file, an IDENTITY file, and a USER file (about me).
Ask me any questions you need, then write all three.
Use Plan Mode.

3. Best practices

  • Make boundaries explicit in the IDENTITY file (“Inbox only. Never touch calendar or payments.”).
  • Keep the outcome in one sentence. If you cannot state it clearly, you are not ready to build.
  • Let Grok interview you. Reverse prompting (ask it to ask you questions) produces better identity files.

4. Practice lab (required)

Choose a simple real need from your work (example: daily activity summary, follow-up reminder list, or support reply helper).

  1. Write the Aim + Definition of Done.
  2. Run the identity-files prompt above with Plan Mode.
  3. Answer Grok’s questions.
  4. Save the three files in a dedicated folder for that agent.
Done when

You have one Aim sentence, one Definition of Done, and three identity files you reviewed and accepted.
