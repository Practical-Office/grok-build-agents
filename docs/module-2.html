Aim + Identity

Before an agent can work well, it needs a clear outcome and a clear identity. All prompts go into the Grok Build CLI.

Where you work

In the terminal:

cd ~/grok-practice
grok

Paste every prompt below into the Grok Build CLI.

Aim for a specific outcome

Do not start by listing steps. Start by stating the result you want.

Weak: “Help with my emails.”

Strong: “Every morning the inbox has drafts ready in my voice, important items are flagged, and nothing important is missed.”

Also write a Definition of Done — one sentence that tells the agent when the job is finished.

Example Aim — paste into Grok to practice

I need an inbox triage helper.
Why this matters: I waste time sorting email every morning.
Definition of Done: Given a list of email subjects, the helper labels each one as Reply now, Reply later, or Archive, and writes a one-line reason.
Use Plan Mode. Ask me any clarifying questions first. Do not make any changes until I approve the plan.

Answer Grok’s questions. Do not approve until the outcome is clear and narrow.

Give the agent an identity

FileWhat it is
SOULPersonality, tone, values, behavior
IDENTITYName, role, job description, hard boundaries
USERWho it works for — your role, priorities, preferences

Identity prompt — paste into Grok Build CLI

I want to build an AI agent that helps with inbox triage only.
Create three identity files in this folder:
1. SOUL.md — personality, tone, values
2. IDENTITY.md — name, role, job description, hard boundaries (inbox only; never touch calendar, payments, or client systems)
3. USER.md — about me: my role, priorities, and preferences

Ask me any questions you need first, then write all three files.
Use Plan Mode. Do not make any changes until I approve the plan.
  1. Answer Grok’s questions honestly.
  2. Read the plan. Confirm it only creates those three files.
  3. Approve, then open each file and check the boundaries are explicit.

Best practices

  • Make boundaries explicit in IDENTITY (“Inbox only. Never touch calendar or payments.”).
  • Keep the outcome in one sentence.
  • Let Grok interview you — answering its questions produces better identity files.
