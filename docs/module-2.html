Aim + Identity

Before an agent can work well, it needs a clear outcome and a clear identity.

Aim for a specific outcome

Do not start by listing steps. Start by stating the result you want.

Weak: “Help with my emails.”

Strong: “Every morning the inbox has drafts ready in my voice, important items are flagged, and nothing important is missed.”

Also write a Definition of Done — one sentence that tells the agent when the job is finished.

I need to [outcome].
Why this matters: [short reason].
Definition of Done: [one clear, measurable sentence].
Use Plan Mode. Ask me any clarifying questions first.

Give the agent an identity

FileWhat it is
SOULPersonality, tone, values, behavior
IDENTITYName, role, job description, hard boundaries
USERWho it works for — your role, priorities, preferences
 
I want to build an AI agent that [paste your Aim / outcome].
Create its three identity files: a SOUL file, an IDENTITY file, and a USER file (about me).
Ask me any questions you need, then write all three.
Use Plan Mode.

Best practices

  • Make boundaries explicit in IDENTITY (“Inbox only. Never touch calendar or payments.”).
  • Keep the outcome in one sentence.
  • Let Grok interview you — reverse prompting produces better identity files.

Practice lab

  1. Write the Aim + Definition of Done.
  2. Run the identity-files prompt with Plan Mode.
  3. Answer Grok’s questions and save the three files.
