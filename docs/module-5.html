Module 5 — Trust Stages + Daily Habits

Building the agent is the easy part. Knowing when to trust it is the hard part.

1. Trust is earned in stages

StageAgent mayYou must
1Propose onlyApprove every step
2Draft / sort / labelReview outputs before use
3Limited pre-approved actionsSpot-check regularly
4Recurring / scheduled workMonitor results + keep guardrails

Never jump from Stage 1 to Stage 4. Most team agents should stay at Stage 2 or 3 for a long time.

2. Daily habits

  • Start every non-trivial request with Plan Mode.
  • Keep each agent in its own folder.
  • After something works, run /skillify.
  • Re-read the IDENTITY boundaries before expanding what an agent can do.
  • If results drift, tighten the playbook or identity files instead of adding more power.

3. When to stop

Stop and escalate if
  • The plan is unclear or too broad
  • The agent asks for access you are not comfortable giving
  • Outputs look wrong or inconsistent
  • You cannot explain what the agent is about to do

4. Team handoff

When you create a useful agent or skill:

  1. Put it in a clearly named folder.
  2. Include the Aim, Definition of Done, identity files, and playbook.
  3. Note the current Trust Stage.
  4. Tell the team where it lives and what it is allowed to do.

5. Final practice

Take one of the agents from Module 4 and:

  1. Write its current Trust Stage in a short README inside the folder.
  2. List two things it is allowed to do and two things it must never do.
  3. Share the folder location with one teammate and walk them through how to use it safely.
