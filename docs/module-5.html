Trust Stages + Daily Habits

Building the agent is the easy part. Knowing when to trust it is the hard part. Record the stage inside the agent folder via Grok Build CLI.

Trust is earned in stages

1Propose only — you approve everything
2Draft / sort — you review before use
3Limited actions — you spot-check
4Scheduled work — you monitor

Never jump from Stage 1 to Stage 4. Most team agents stay at Stage 2 or 3 for a long time.

Promotion gates (short version)

Gates: 3 good runs → Stage 2 · 5 good outputs, zero violations → Stage 3 · 2 weeks, no escalations → Stage 4 candidate · team lead approval for Stage 4

When to ask the AI first

Use these when the job is clear and the risk is low — you are tightening the same agent, not expanding its power:

  • Plan is long, unclear, too broad, or keeps growing → paste: Simplify the plan. Keep only the minimum steps. Use Plan Mode.
  • Output is almost right → ask for one small fix; reject plans that rewrite everything
  • You forgot a boundary → tell it to update IDENTITY or AGENTS.md; approve boundary changes only if they add boundaries or tighten existing ones — never if they remove or soften
  • Something worked once → run /skillify (one successful task — trust promotion still uses the gates above)
  • Ask-AI-first is OK for a small cluster of related fixes in one plan — escalate if scope grows, access/permissions, or you are unsure

You must still understand the plan before you approve. “Ask the AI” does not mean “let it run until it looks done.”

When to escalate to a human

Stop the agent. Do not approve. Do not keep prompting until it “works.”

  • Plan is unclear or too broad (after one clarify attempt)
  • Agent wants access you are not comfortable giving
  • Results look wrong or inconsistent
  • You cannot explain what it is about to do
  • Install or permissions fail

Stop the agent. Ask a person with the folder path and what you tried.

Daily habits + after the course

  • Plan Mode order: (1) say Use Plan Mode or paste the sentence, (2) /plan, (3) Shift+Tab until on.
  • Keep each agent in its own folder.
  • After something works once, run /skillify.
  • Re-read IDENTITY boundaries before expanding power.
  • If results drift, tighten the playbook — do not add more power.
  • Daily or weekly ritual: pick one named agent for a recurring job (example: follow-up drafts every morning).
  • On demand: cd into the right agent folder (not the practice folder) and start a fresh grok session.
