Trust is earned in stages

StageAgent mayYou must
1Propose onlyApprove every step
2Draft / sort / labelReview outputs before use
3Limited pre-approved actionsSpot-check regularly
4Recurring / scheduled workMonitor results + keep guardrails

Never jump from Stage 1 to Stage 4. Most team agents stay at Stage 2 or 3 for a long time.

Promotion gates (short version)

  • Stage 1 → 2: 3 correct plans + outputs in a row
  • Stage 2 → 3: 5 correct outputs, zero boundary violations
  • Stage 3 → 4: documented success + no escalations for 2 weeks
  • Stage 4: explicit approval from team lead

When to ask the AI first

Use these when the job is clear and the risk is low — you are tightening the same agent, not expanding its power:

  • Plan is long or fuzzy → paste: Simplify the plan. Keep only the minimum steps. Use Plan Mode.
  • Output is almost right → ask for one small fix; reject plans that rewrite everything
  • You forgot a boundary → tell it to update IDENTITY or AGENTS.md; approve only if boundaries get stricter or stay the same
  • Something worked once → run /skillify

You must still understand the plan before you approve. “Ask the AI” does not mean “let it run until it looks done.”

When to escalate to a human

Stop the agent. Do not approve. Ask a teammate, team lead, or IT — with the folder path and what you already tried:

  • You cannot explain what the agent is about to do
  • It asks for access, money, client data, or external send you have not approved
  • Outputs look wrong or inconsistent after one clarify attempt
  • The plan keeps growing past one job or one folder
  • Install, sign-in, or permissions fail
  • You feel pressure to “just approve” so you can move on

Escalate means a person, not another AI chat.

Daily habits + after the course

  • Start every non-trivial request with Plan Mode (/plan, Shift+Tab, or the paste sentence).
  • Keep each agent in its own folder.
  • After something works, run /skillify.
  • Re-read IDENTITY boundaries before expanding power.
  • If results drift, tighten the playbook — do not add more power.
  • Daily or weekly ritual: pick one named agent for a recurring job (example: follow-up drafts every morning).
  • On demand: for other jobs, cd into the right agent folder and start a new grok session.

Manager agents (later)

After you have at least two narrow agents in separate folders, you may later add a Manager that routes jobs to the right folder. A Manager never does the work — you still open the worker folder and use Plan Mode there. The core course does not include a Manager build lab.
