Setup
Pre-requisite · hard gate · ~25–35 min

Skills setup

Install Grok Build, sign in, and prove it works. Do not start Module 1 until this page is complete.

Hard gate

You must finish every step below and confirm the checklist at the end. If install fails, stop and get help. Do not skip ahead.

What you need

  • A computer (macOS, Windows, or Linux)
  • Internet connection
  • Permission to install software (ask IT if on a work machine)
  • A Grok / SuperGrok or X Premium+ account that can use Grok Build

You do not need to know how to code.

Exact steps

1. Open a terminal

  • macOS: Cmd + Space → Terminal
  • Windows: PowerShell or Git Bash
  • Linux: Terminal app

2. Install Grok Build

macOS / Linux / Git Bash:

curl -fsSL https://x.ai/cli/install.sh | bash

Windows PowerShell:

irm https://x.ai/cli/install.ps1 | iex

3. Check the install

grok --version

You should see a version number.

4. Sign in

  1. Type grok and press Enter.
  2. Sign in in the browser that opens.
  3. Return to the terminal — you should see the Grok interface.

5. Run the official short tour

/tour

Walk through the tips. Required.

6. First proof it works

Create a file called hello.txt that contains the sentence: Grok Build is working.
Use Plan Mode. Do not make any changes until I approve the plan.
  1. Read the plan.
  2. Approve only if it makes sense.
  3. Confirm hello.txt exists with the correct sentence.
