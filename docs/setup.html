Setup

Install Grok Build, sign in, and prove it works. Do not start Module 1 until this page is complete.

Hard gate

You must finish every step below and confirm the checklist at the end. If install fails, stop and get help. Do not skip ahead.

1. What you need

  • A computer (macOS, Windows, or Linux)
  • Internet connection
  • Permission to install software (ask IT if you are on a work machine)
  • A Grok / SuperGrok or X Premium+ account that can use Grok Build

You do not need to know how to code.

2. Open a terminal

A terminal is a text window where you type commands.

  • macOS: Press Cmd + Space, type Terminal, press Enter.
  • Windows: Use PowerShell or install Git for Windows and open Git Bash.
  • Linux: Open your Terminal app (often Ctrl + Alt + T).
What you will see: A window with a blinking cursor. That is normal.

3. Install Grok Build

Copy the command for your system, paste it into the terminal, and press Enter.

macOS / Linux / Git Bash:

curl -fsSL https://x.ai/cli/install.sh | bash

Windows PowerShell:

irm https://x.ai/cli/install.ps1 | iex
What success looks like: The script finishes without a big red error. If you see “command not found: grok” afterward, close the terminal completely, open a new one, and try the next step.

4. Check the install

In a new terminal window, run:

grok --version

You should see a version number. Write it down.

5. Sign in

  1. Type grok and press Enter.
  2. A browser window should open. Sign in with your account.
  3. Return to the terminal. You should now see the Grok interface (history area + typing box at the bottom).
What you will see: A full-screen (or nearly full-screen) Grok session ready for you to type.

6. Run the official short tour

Inside Grok, type:

/tour

(Same as /tutorial or /onboarding.)

Walk through the short tips. Press the arrow keys or follow the on-screen instructions. This takes a few minutes and is required.

7. First proof it works

Still inside Grok, type exactly this:

Create a file called hello.txt that contains the sentence: Grok Build is working.
Use Plan Mode. Do not make any changes until I approve the plan.

Then:

  1. Read the plan Grok shows you.
  2. Approve it only if it makes sense.
  3. Confirm the file hello.txt was created and contains the correct sentence.
Success checklist (all required)
  • grok --version shows a version number
  • You can open Grok and sign in
  • You completed /tour
  • You created hello.txt using Plan Mode and approved the plan yourself

When every box is done, go to Module 1.
