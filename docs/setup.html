Setup
Pre-requisite · hard gate · ~25–35 min

Setup

Install Grok Build locally, sign in, and prove Plan Mode works. Do not start Module 1 until this page is complete.

Hard gate

Finish every step below. If anything fails, stop and get help. Do not start Module 1 until the checklist is complete.

What you need

  • A computer (macOS, Windows, or Linux)
  • Internet connection
  • Permission to install software (ask IT if on a work machine)
  • A Grok / SuperGrok or X Premium+ account that can use Grok Build

You do not need to know how to code.

Where everything happens

  • Terminal = the place you type install commands and start Grok (Terminal on Mac, PowerShell on Windows).
  • Grok Build CLI = the interactive session that starts after you type grok. All agent work happens inside this session.
  • Your folder = a folder on your computer where Grok is allowed to create files.

1. Open a terminal

  • macOS: Press Cmd + Space, type Terminal, press Enter.
  • Windows: Open PowerShell (or Git Bash if you have it).
  • Linux: Open your Terminal app.

2. Install Grok Build (in the terminal)

macOS / Linux / Git Bash — paste this:

curl -fsSL https://x.ai/cli/install.sh | bash

Windows PowerShell — paste this:

irm https://x.ai/cli/install.ps1 | iex

3. Check the install (in the terminal)

grok --version

You should see a version number. If you do not, stop and get help.

4. Create a practice folder (in the terminal)

mkdir -p ~/grok-practice
cd ~/grok-practice
pwd

Stay in this folder for the rest of Setup.

5. Start Grok Build (in the terminal, inside the practice folder)

grok
  1. Sign in in the browser that opens.
  2. Return to the terminal — you should see the Grok Build interface.

From this point, paste into the Grok Build CLI.

6. Run the official short tour (inside Grok Build CLI)

/tour

7. First proof — Plan Mode (inside Grok Build CLI)

Copy the entire block and paste into Grok:

Create a file called hello.txt that contains exactly this sentence:
Grok Build is working.

Use Plan Mode. Do not make any changes until I approve the plan.
  1. Read the plan. Approve only if it only creates hello.txt.
  2. Confirm the file: in a separate terminal run cat ~/grok-practice/hello.txt

Success checklist (must complete)
