Quick reference

Keep this open while you work in the Grok Build CLI.

Always paste this with real requests

Use Plan Mode. Do not make any changes until I approve the plan.

Or type /plan, or press Shift+Tab. After you approve, Grok may leave Plan Mode — return before your next ask.

Start a session (terminal)

cd ~/agents/your-agent-name
grok

Use the same terminal: exit any old grok if running, cd to the right folder (that agent’s folder, not the practice folder), then start a fresh grok session. A second terminal is fine if you prefer.

AGENT framework

AAim — outcome + Definition of Done
GGive identity — SOUL, IDENTITY, USER
EEquip — context, tools, playbooks
NNarrow — one agent, one lane
TTrust — stages 1 → 4, never jump

SOUL / IDENTITY / USER = who the agent is. AGENTS.md = rules, boundaries, trust stage, stop conditions.

Six team rules

  1. Plan Mode for non-trivial work
  2. Never approve what you do not understand
  3. One agent = one job
  4. No money / client data / external systems until proven
  5. If unsure → stop and ask a human
  6. Save good work with /skillify

Trust stages + promotion gates

1Propose only — you approve everything
2Draft / sort — you review before use
3Limited actions — you spot-check
4Scheduled work — you monitor

Gates: 3 good runs → Stage 2 · 5 good outputs, zero violations → Stage 3 · 2 weeks, no escalations → Stage 4 candidate · team lead approval for Stage 4

Stage 3 short log: while at Stage 3, write a short spot-check note with the agent (agent folder / AGENTS.md) — date, what you checked, pass/fail.

Ask the AI first

  • Long or unclear plan (too broad or keeps growing) → Simplify the plan. Keep only the minimum steps. Use Plan Mode.
  • Almost right → one small fix only
  • Missing boundary → update IDENTITY or AGENTS.md; approve only if boundaries get stricter or stay the same
  • Worked once → /skillify (one successful task — not a streak)
  • Small cluster of related fixes in one plan is OK — escalate if scope grows, access/permissions, or unsure

When to escalate to a human

  • Plan is unclear or too broad (after one clarify attempt)
  • Agent wants access you are not comfortable giving
  • Results look wrong or inconsistent
  • You cannot explain what it is about to do
  • Install or permissions fail

Stop the agent. Ask a person with the folder path and what you tried.

After the course

  • Ritual: one named agent for a recurring daily or weekly job
  • On demand: cd to the right folder, new grok session
  • Manager: optional coordination agent — routes to agent folders only; never does the work
