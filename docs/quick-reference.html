Always say this

Use Plan Mode. Do not make any changes until I approve the plan.

AGENT framework

AAim — outcome + Definition of Done
GGive identity — SOUL, IDENTITY, USER
EEquip — context, tools, playbooks
NNarrow — one agent, one lane
TTrust — stages 1 → 4, never jump

Six team rules

  1. Plan Mode for non-trivial work
  2. Never approve what you do not understand
  3. One agent = one job
  4. No money / client data / external systems until proven
  5. If unsure → stop and ask
  6. Save good work with /skillify

Trust stages

1Propose only — you approve everything
2Draft / sort — you review before use
3Limited actions — you spot-check
4Scheduled work — you monitor

Stop if

  • Plan is unclear or too broad
  • Agent wants access you are not comfortable giving
  • Results look wrong
  • You cannot explain what it is about to do
